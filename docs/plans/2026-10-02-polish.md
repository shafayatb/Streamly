# Polish (launcher icon, splash, Baloo Da 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Streamly a branded launcher icon, a branded splash that stays until the start
screen is known, and the mockups' typeface (Baloo Da 2) on every screen.

**Architecture:** The icon and splash live in `:androidApp` resources plus `MainActivity`; the
splash reads the existing `AppViewModel.state` (no new logic in `:shared`). The typeface is four
static TTFs in `:core:designsystem` Compose resources, applied once in `StreamlyTheme` through
Material 3's `Typography(fontFamily = …)` constructor, so no screen changes.

**Tech Stack:** `androidx.core:core-splashscreen` 1.2.0, Compose Multiplatform resources
(`Font(Res.font…)`), Material 3 (JB 1.12.0-alpha03 → androidx 1.5.0-alpha22), Android adaptive
icons, fontTools and Pillow (scratch tooling only, not committed).

**Spec:** this file. The design was agreed in chat on October 2 (summary below).

## Agreed design (brainstorming, October 2)

Context: the user re-sequenced the release: features first (`feature/polish` →
`feature/watch-history` → `feature/settings`), then one release gate on `release/1.0`. This is the
first of those features.

- **Scope (user):** a branded launcher icon, a branded splash, and Baloo Da 2 everywhere (body
  text included), as in the mockups. Not headings only.
- **Icon (user: "the onboarding mark"):** the indigo brand gradient (Indigo900 `#1C2378` →
  Indigo500 `#3F51D6`, top-left to bottom-right, as `BrandBackground`) behind the frosted rounded
  tile (white at 18%, corner radius 30% of the tile) with the white play glyph, exactly the
  geometry of `StreamlyLogo`. A monochrome layer (tile with the glyph cut out) for themed icons.
  Legacy PNGs for API 24–25 rendered from the same geometry. The template robot is removed.
- **Splash (agreed section 1):** `core-splashscreen` backports the Android 12 splash to API 24.
  `Theme.Streamly.Starting`: Indigo900 background, the icon foreground as the splash icon,
  `postSplashScreenTheme` = the current `@android:style/Theme.Material.Light.NoActionBar`. Same in
  light and dark (a brand surface, like onboarding). `MainActivity` gets `AppViewModel` from Koin,
  keeps the splash while `state.value == AppState.Loading`, and passes that ViewModel into
  `App(viewModel = …)`. Default exit (fade). The `Loading` branch in `App` stays as a fallback.
- **Font (agreed section 2):** Google Fonts ships Baloo Da 2 only as a variable font
  (`wght` 400–800), whose weights do not apply below API 26 (`minSdk` is 24). So four static
  instances (Regular 400, Medium 500, SemiBold 600, Bold 700) are cut with fontTools, full glyph
  set including Bengali (about 270 KB each, 1.1 MB in total). The OFL declares no Reserved Font
  Name, so instancing is allowed; `OFL.txt` is committed next to the fonts' module.
- **Tests:** a device test that fails today (no family set) pins every style to the Baloo family
  with the four weights; the splash and icon have no new logic and are checked on devices.

## Review Focus

1. **Baloo's tall vertical metrics** (hhea ascent 1095 + descent 589 = 1.684 em, against
   Material's 1.5 em line height): text in fixed-height pills, chips, the tab bar, the Player's
   action row, and dialog buttons may be clipped or sit off-centre. Expected: every label fully
   visible and vertically centred. Pinned by Task 4 step 4 (screens at 360 dp on the A04, light and
   dark), with a fix in `StreamlyTheme` (`LineHeightStyle`) if needed, not per screen.
2. **Wider glyphs truncating labels at 360 dp** ("Downloaded" was already tight on the A04;
   chips, tab labels, card titles, and the Profile rows). Expected: no new ellipsis on a label
   that fit before. Pinned by Task 4 step 4.
3. **Splash never hangs and never re-appears.** Rotation, a theme switch, and returning from the
   background must not show the splash again (the ViewModel is already `Ready`); a cold start
   while signed in must go splash → Home with no onboarding frame, signed out splash → onboarding.
   Pinned by Task 4 steps 2–3 (frame-by-frame `screenrecord`).
4. **Themed and legacy icons.** Android 13+ themed icons must show the tile/glyph mark, not a blank
   square; launchers that do not mask must show the rounded-square PNG. Pinned by Task 4 step 1
   (themed icons on the emulator). API 24–25 PNGs cannot be checked on our devices (only API 34
   and 36 images are installed) and are recorded as unverified.
5. **Existing device tests keep passing** with the new font (they match text and semantics, which
   must not change). Pinned by Task 1 step 5 and Task 4 step 5.

```kotlin
import androidx.compose.runtime.remember
import androidx.compose.ui.text.font.FontFamily
import org.jetbrains.compose.resources.Font
import streamly.core.designsystem.generated.resources.Res
import streamly.core.designsystem.generated.resources.baloo_da_2_bold
import streamly.core.designsystem.generated.resources.baloo_da_2_medium
import streamly.core.designsystem.generated.resources.baloo_da_2_regular
import streamly.core.designsystem.generated.resources.baloo_da_2_semibold

// Baloo Da 2, the mockups' typeface. Static instances: variable-font weights need API 26.
@Composable
private fun balooDa2(): FontFamily = FontFamily(
    Font(Res.font.baloo_da_2_regular, FontWeight.Normal),
    Font(Res.font.baloo_da_2_medium, FontWeight.Medium),
    Font(Res.font.baloo_da_2_semibold, FontWeight.SemiBold),
    Font(Res.font.baloo_da_2_bold, FontWeight.Bold),
)

private fun streamlyTypography(fontFamily: FontFamily): Typography =
    Typography(fontFamily = fontFamily).run {
        copy(
            displaySmall = displaySmall.copy(fontWeight = FontWeight.Bold),
            headlineLarge = headlineLarge.copy(fontWeight = FontWeight.Bold),
            headlineMedium = headlineMedium.copy(fontWeight = FontWeight.Bold),
            headlineSmall = headlineSmall.copy(fontWeight = FontWeight.Bold),
            titleLarge = titleLarge.copy(fontWeight = FontWeight.Bold),
            titleMedium = titleMedium.copy(fontWeight = FontWeight.SemiBold),
            labelLarge = labelLarge.copy(fontWeight = FontWeight.SemiBold),
        )
    }

@Composable
public fun StreamlyTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit,
) {
    val fontFamily = balooDa2()
    val typography = remember(fontFamily) { streamlyTypography(fontFamily) }
    MaterialTheme(
        colorScheme = if (darkTheme) DarkColors else LightColors,
        typography = typography,
        content = content,
    )
}
```

- [ ] **Step 5: Render the legacy PNGs** (API 24–25), scratch script, 4× supersampled:

```python
from PIL import Image, ImageDraw
SIZES = {"mdpi": 48, "hdpi": 72, "xhdpi": 96, "xxhdpi": 144, "xxxhdpi": 192}
A, B = (0x1C, 0x23, 0x78), (0x3F, 0x51, 0xD6)

def full_icon(px):  # the 108-unit adaptive icon at px*108/72 so the visible 72 units = px
    n = round(px * 108 / 72) * 4
    k = n / 108
    img = Image.new("RGBA", (n, n))
    pix = img.load()
    for y in range(n):
        for x in range(n):
            t = (x + y) / (2 * (n - 1))
            pix[x, y] = tuple(round(a + (b - a) * t) for a, b in zip(A, B)) + (255,)
    tile = Image.new("RGBA", (n, n), (0, 0, 0, 0))
    d = ImageDraw.Draw(tile)
    d.rounded_rectangle([28 * k, 28 * k, 80 * k, 80 * k], radius=15.6 * k, fill=(255, 255, 255, 46))
    d.polygon([(47.34 * k, 43.6 * k), (64.4 * k, 54 * k), (47.34 * k, 64.4 * k)], fill=(255, 255, 255, 255))
    img = Image.alpha_composite(img, tile)
    m = 18 * k  # crop to the 72-unit visible area
    return img.crop((m, m, n - m, n - m))

for density, px in SIZES.items():
    art = full_icon(px)
    s = art.size[0]
    for name, mask_draw in [
        ("ic_launcher", lambda d: d.rounded_rectangle([0, 0, s - 1, s - 1], radius=s * 0.18, fill=255)),
        ("ic_launcher_round", lambda d: d.ellipse([0, 0, s - 1, s - 1], fill=255)),
    ]:
        mask = Image.new("L", (s, s), 0)
        mask_draw(ImageDraw.Draw(mask))
        out = Image.new("RGBA", (s, s), (0, 0, 0, 0))
        out.paste(art, (0, 0), mask)
        out.resize((px, px), Image.LANCZOS).save(f"androidApp/src/main/res/mipmap-{density}/{name}.png")
```
